# Asansörde Yanlış Kat Butonuna Bakanların İtirafnamesi

> **Resmî Uyarı:** Bu depo bir şaka değildir. Şaka gibi durması, şaka olmadığının en güçlü kanıtıdır.

## Problem Tanımı (Bilimsel)

İnsanlık tarihi boyunca iki tür felaket yaşanmıştır:

1. Yanlış kata bakıp doğru butona basmak
2. Doğru kata bakıp yanlış butona basmak

Üçüncü bir felaket daha vardır: bunu kimseye itiraf etmemek.

Bu yazılım üçüncü felaketi çözer. Kabinde, koridorda veya evde çalıştırılabilir. Asansörün kendisi şu an desteklenmemektedir; asansörler gururludur.

## Kurulum

```bash
python3 itiraf.py
```

Başka bir şey gerekmez. Pip yok, Docker yok, Kubernetes yok. Sadece vicdan ve Python 3 vardır.

## Kullanım Senaryosu

1. Asansöre binin.
2. Yanlış butona bakın.
3. Bastığınızı fark edin.
4. Bu programı açın.
5. İtiraf edin.
6. Kapı açılsın. Siz de açılın.

## Mimari

- `itiraf.py` — çekirdek vicdan motoru
- rastgele bahane üreteci (patent bekleniyor)
- yavaş yazı efekti (çünkü pişmanlık aceleye gelmez)

## Sık Sorulan Sorular

**Bu gerçekten çalışıyor mu?**  
Evet. Terminalde çalışır. Asansörde çalışması sizin elinizde.

**Neden Türkçe?**  
Çünkü yanlış kata basmak evrenseldir ama bahane üretmek yerel bir sanattır.

**Siyasi bir mesaj var mı?**  
Hayır. Asansör tarafsızdır. Butonlar da. Yorum satırları ise sadece yorum satırıdır.
